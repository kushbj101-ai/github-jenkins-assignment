FINAL CHALLENGE: "WHAT HAPPENS WHEN I RUN 'git push'?"
============================================================
1. Git: Sends committed branch changes to the remote repository.
2. GitHub: Accepts the commit, updates the 'main' branch, and fires an active push event.
3. Webhook: GitHub issues an HTTP POST payload to Jenkins at /github-webhook/.
4. Jenkins: Receives payload, matches the repository/branch, and triggers the job.
5. Build: Jenkins clones the updated code, executes the shell script, and outputs SUCCESS.
